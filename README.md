### 👨‍💻 About Me

I am a **Computer Engineering graduate from Samar State University** with a passion for building robust, scalable web applications that solve tangible operational bottlenecks. 

Rather than just building classroom exercises, I focus on building practical, business-ready software:
- 🚀 **Production Experience:** Engineered and deployed the **TK Sports Center Platform**—a custom full-stack management web application replacing paper and spreadsheets with automated reservations, payment receipts, expense logging, and sales analytics.
- 🏛️ **Professional Background:** Completed OJT and the Government Internship Program (GIP) at the **Department of Information and Communications Technology (DICT)**, conducting digital literacy trainings and managing hardware, router configurations, and network infrastructure.
- 🎯 **Career Goal:** Junior Software Engineer / Full-Stack Developer specializing in **Java, Spring Boot, and Angular**.
- 🌱 **Currently Leveling Up In:** Microservices architecture, Docker containerization, REST API optimization, and CI/CD pipelines.
